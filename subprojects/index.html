Engineering Investigations

This is a collection of my engineering investigations where I created small projects to explore different engineering concepts. Also home to in-progress work.

Pendulum Desk Toy

I created a pendulum to to investigate the creation of rotational motion in 3D Printing.

Solder-welded the joints to create a stable structure.

Middle School Coding (Minecraft Mods, Java, Lua, etc. )

Learned the basics of Java and therefore C++, making simple projects like a workout plan generator based on different difficulty levels, time duration, and exercise length.

I garnered over eight thousand downloads between two of my mods, updating consistently for 2 years.

4x4 Matrix Keypad

  • Used whiteboard for envisionment of the electrical and coding logic.
  • Coded custom logic for handling keypress events.

Basic Transistor H-Bridge

  • Built and tested a basic transistor H-bridge circuit for motor control.
  • Was successful in demonstrating the concept.

Star Citizen Button Box

Created a button box using the logic learned from the 4x4 Matrix Keypad project for toggle switches instead.

First big soldering project, requiring me to learn proper technique and find tricks to get tricky wires soldered.

Used the USB HID Keyboard library to interface with the computer.
